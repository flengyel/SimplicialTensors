# Computations with diagonal simplicial tensor modules

The [manuscript](dstm_short.pdf) is built from [dstm_short.tex](dstm_short.tex),
[generated_section.tex](generated_section.tex), [dendroidal_section.tex](dendroidal_section.tex),
and the [bibliography](dstm_short.bib). The [arXiv source archive](submissions/dstm_v3_arxiv_source.tar.gz)
includes the LaTeX sources, the compiled bibliography, and two [ancillary programs](anc/README.txt).

## Reproduce the calculations

From the repository root, install the package with `python -m pip install -e .` and run the commands below.

| Manuscript calculation | Command |
| --- | --- |
| §§2–3. [Shape $(3,5)$, vector boundary, homology generated by $E_{01}$, and the degenerate horn filler with free entries $(6,8)$](anc/dstm_examples.py) | `python tex/anc/dstm_examples.py` |
| §§4–5. [Normalized ranks $(1,3,2)$ and images under the differential for square matrices. Contraction on matrix units through degree two.](anc/dstm_examples.py) | `python tex/anc/dstm_examples.py` |
| §6. [The kernels of the matrix units $E_{01}$ and $E_{10}$, and the cycle and boundary dimensions for shifts $(1,1)$](anc/dstm_examples.py) | `python tex/anc/dstm_examples.py` |
| §6.1. [Lift of a quotient isomorphism to a chain automorphism](../experiments/kernel_sequences.py) | `python experiments/kernel_sequences.py --case lifting --matrices` |
| §6.2. [Realization of a kernel and two obstructions to realization](../experiments/kernel_sequences.py) | `python experiments/kernel_sequences.py --case realize` and `python experiments/kernel_sequences.py --case obstruction` |
| §6.3. [Homology of the matrix family at $t=4$ over the rationals and over the field of three elements](../experiments/kernel_sequences.py) | `python experiments/kernel_sequences.py --case jump --parameter 4` and `python experiments/kernel_sequences.py --case jump --parameter 4 --modulus 3` |
| §6.3. [Reduced simplicial spheres in degrees 1 through 3](../experiments/kernel_sequences.py) | `python experiments/kernel_sequences.py --case spheres --max-degree 3` |
| §6.4. [Petersen incidence complex from normalized tensor faces](anc/rank_shifted_homology.py) | `python tex/anc/rank_shifted_homology.py` |
| §6.5. [Mod-2 boundary of the original ordered adjacency matrix, for all 1,536 affine orders of each of the rook and Shrikhande graphs](../experiments/affine_boundary_ranks.py) | `python experiments/affine_boundary_ranks.py` |
| §6.5 and Figure 1. [Insertion for the three-vertex path and the original boundaries of the complete and edgeless four-vertex graphs](../experiments/interleaved_graph_paths.py) | `python experiments/interleaved_graph_paths.py --small-examples` |
| §6.5. [Full boundary rank after insertion of isolated vertices, counted by oriented Hamiltonian paths in the Petersen, rook, and Shrikhande graphs](../experiments/interleaved_graph_paths.py) | `python experiments/interleaved_graph_paths.py` |
| §6.5. [Entire mod-2 boundary rank distribution after insertion, over all vertex orders of each of the three graphs](../experiments/interleaved_rank_distributions.py) | `python experiments/interleaved_rank_distributions.py` |
| §7. [Two-vertex tree with two tensor axes, including the kernel and cokernel of restriction to the omitted face](../experiments/two_vertex_tensor_horn.py) | `python experiments/two_vertex_tensor_horn.py` |
| Appendix A. [Kernel planes of two matrices and the excluded plane on the locus of maximal ranks](../experiments/kernel_sequences.py) | `python experiments/kernel_sequences.py --case marked --matrices` and `python experiments/kernel_sequences.py --case obstruction` |
| Appendix A. [Degree-zero kernel planes for all $3\times3$ binary matrices with maximal ranks](../experiments/three_by_three_kernels.py) | `python experiments/three_by_three_kernels.py` |

The [Petersen coset calculation](../experiments/petersen_brd_right_cosets.py) also gives the boundary rank distribution of the original adjacency matrix over all $10!$ orders. Run `python experiments/petersen_brd_right_cosets.py`. The [experiment catalogue](../docs/experiments_catalog.md) lists the other computations in the repository.

For a dense hypermatrix, [`generated_homology`](../src/simplicial_tensors/homology.py) uses the simplicial dimension of its shape. For a [`SparseTensor`](../src/simplicial_tensors/rank_shifted.py) with a specified degree and shifts, [`sparse_generated_homology`](../src/simplicial_tensors/tensor_chain_complex.py) uses that grading. Both functions return the chain dimensions, differential ranks and Betti numbers over the rationals or the specified prime field. [API and examples](../docs/api/chain_complex.md)

## Build and package the manuscript

From the repository root, run

```sh
cd tex
latexmk -pdf -interaction=nonstopmode -halt-on-error dstm_short.tex
```

To package the current source for arXiv, build the manuscript first and run the following from `tex/`.

```sh
mkdir -p submissions
tar -czf submissions/dstm_v3_arxiv_source.tar.gz dstm_short.tex generated_section.tex \
  dendroidal_section.tex dstm_short.bib dstm_short.bbl anc
```
