Examples for Computations with diagonal simplicial tensor modules

Use Python 3.10 or later. From the repository root, install the package
in a virtual environment and run:

    python -m pip install -e .
    python tex/anc/dstm_examples.py
    python tex/anc/rank_shifted_homology.py

The first script computes the shape (3,5) example, the vector boundary,
the submodules generated by E_01 and E_10, and the matrix horn filler.
It computes the normalized ranks and differentials for square matrices,
checks the contraction on matrix units in degrees 0 through 2, and computes
the cycle and boundary dimensions for shifts (1,1).

The second script computes ranks over the rationals. For the
Petersen graph, the normalized chain groups in degrees 0 and 1 have
dimensions 10 and 15, the incidence map has rank 9, and the Betti
numbers are 1 and 6. It also computes the reduced homology of the smash
product of two simplicial circles.

For a source-only manuscript package, first clone the repository and
install its package. The scripts in this directory require that package.

Commands for the graph boundary rank distributions, the kernel calculations,
and the two-vertex tree are listed in the repository at
https://github.com/flengyel/SimplicialTensors/blob/a65c869aa5c7cd9d091fc623aa80855f62c0d51a/tex/README.md
