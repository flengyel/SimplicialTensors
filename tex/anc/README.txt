Examples for Computations with simplicial tensor modules

Use Python 3.10 or later. From the repository root, install the package
in a virtual environment and run:

    python -m pip install -e .
    python tex/anc/dstm_examples.py
    python tex/anc/rank_shifted_homology.py

The first script computes vector faces, the submodule generated by E_01,
and a matrix horn. The second uses sparse rank-shifted tensors and exact
rational ranks. It reports normalized chain ranks 10 and 15, incidence
rank 9, and Betti numbers 1 and 6 for the Petersen graph. It also computes
the reduced circle-smash complex.

For a source-only manuscript package, first clone the repository and
install its package. The scripts in this directory require that package.
