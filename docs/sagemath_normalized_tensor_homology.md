# Rational relative-homology example

[experiments/sagemath_normalized_tensor_homology.py](../experiments/sagemath_normalized_tensor_homology.py) computes exact relative homology using NumPy and SymPy. SageMath is optional. The `SymbolicTensor` class is imported from the package rather than implemented again in the experiment.

Run from an installed checkout.

~~~sh
python experiments/sagemath_normalized_tensor_homology.py
python experiments/sagemath_normalized_tensor_homology.py --modulus 3
~~~

For `T = np.arange(8).reshape(2,2,2)`, the default rational computation gives relative Betti numbers $(0,0)$ when face 0 is omitted and $(0,1)$ when face 1 is omitted. The quotient is by the simplicial submodule generated by the included face, as defined in [the relative-homology experiment](normalized_moore_complex_homology.md).

`compute_relative_homology_rank(tensor, j_horn_excluded_face, *, modulus=None)` returns the relative homology dimension in the degree of the supplied tensor. It accepts a NumPy array or a package `SymbolicTensor` with integer or rational entries. Unevaluated entry symbols are rejected. The default coefficient field is $\mathbb Q$, and an optional prime modulus selects $\mathbb F_p$.

`compute_homology_rank(diffs, n, *, chain_dimension=None)` computes rational homology from exact differential matrices. The dictionary key is the source degree, so `diffs[n]` represents $\partial_n:C_n\to C_{n-1}$. The helper checks dimensions and $\partial_n\partial_{n+1}=0$. It infers $\dim C_n$ from either adjacent differential. If both are absent, an explicit `chain_dimension` is required. This includes an isolated degree-zero chain group.

For example, the incidence differential of a path gives $\dim H_0=1$.

~~~python
from sympy import Matrix
from experiments.sagemath_normalized_tensor_homology import compute_homology_rank

incidence = Matrix([[-1, 0], [1, -1], [0, 1]])
assert compute_homology_rank({1: incidence}, 0) == 1
~~~

The tensor calculation delegates to [the exact normalized implementation](homology.md), which imposes linear relations in the ambient tensor module. It constructs no free basis indexed by distinct encountered arrays.
