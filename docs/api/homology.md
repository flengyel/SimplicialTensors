# Exact homology of tensor-generated submodules

The module [homology.py](../../src/simplicial_tensors/homology.py) computes normalized homology of the simplicial submodule generated by one integer or rational tensor. It uses exact ranks over $\mathbb Q$ or a prime field $\mathbb F_p$.

~~~python
import numpy as np
from simplicial_tensors.homology import generated_homology

circle = np.array([[0, 1], [0, 0]], dtype=object)
result = generated_homology(circle)
assert result.chain_dimensions == (0, 1)
assert result.boundary_ranks == (0, 0)
assert result.homology_dimensions == (0, 1)
~~~

For a tensor of shape $s=(s_1,\ldots,s_k)$, put $n=\min(s)-1$. Its fixed rectangular offsets are $s_a-n-1$. The submodule generated by the tensor is the linear span of its simplicial images, with the linear relations inherited from the ambient tensor module.

In degree $q$, enumerate the injective maps $[q]\to[n]$ and take the corresponding face images. Keep each axis's tail coordinates. Apply the normalization projection

$$
P_q=(1-s_0d_1)(1-s_1d_2)\cdots(1-s_{q-1}d_q),
$$

with the rightmost factor applied first. The resulting columns span

$$
N_q=\bigcap_{i=1}^q\ker d_i.
$$

The normalized differential is $d_0$ in positive degrees and zero in degree zero. If $c_q=\dim N_q$ and $r_q=\operatorname{rank}(d_0|_{N_q})$, then

$$
\dim H_q=c_q-r_q-r_{q+1},\qquad r_0=0.
$$

Only degrees $0\le q\le\min(n,k)$ can contribute. Higher degrees vanish. `GeneratedHomology` stores the tuples `chain_dimensions`, `boundary_ranks`, and `homology_dimensions` in ascending degrees. The boundary rank at index $q$ has source degree $q$. The tuples are understood to be zero beyond their last index.

`generated_homology(tensor, modulus=p)` reduces the entries to $\mathbb F_p$ before normalization. A rational denominator divisible by $p$ is rejected. Floating-point entries and composite moduli are rejected. Use Python integers, `Fraction`, or SymPy rationals for exact input.

`relative_horn_homology(tensor, missing_face, *, modulus=None)` takes the quotient by the submodule generated by all faces except the specified face. If its normalized subspace is $L_q\subseteq N_q$, then the quotient differential has rank

$$
\dim\bigl(d_0(N_q)+L_{q-1}\bigr)-\dim L_{q-1}.
$$

The routine computes this rank together with $\dim N_q-\dim L_q$. The omitted face must belong to a tensor of positive degree.

These functions return dimensions over fields. They do not compute integral torsion or explicit homology bases. The [examples](../experiments/homology_basis.md) include a nonzero $H_1$ generated by $E_{01}$, although the full ambient simplicial tensor module is contractible. Ordinary graph homology uses the [separate graph chain representation](rank_shifted.md).

The notebook adapter [homology_basis_with_degeneracy_check_dask.py](../../src/simplicial_tensors/notebooks/homology_basis_with_degeneracy_check_dask.py) also uses the exact relative-homology routine. Its coordinate-unit counts are reported separately from homology dimensions. The module requires no Dask. Run it with `python -m simplicial_tensors.notebooks.homology_basis_with_degeneracy_check_dask`.

The adapter [homology_basis_dask.py](../../src/simplicial_tensors/notebooks/homology_basis_dask.py) delegates its retained `full_homology_verification` entry point to the same exact routine. Running it as a module checks zero, circle, and horn-quotient examples against their known dimensions.

## Chain-level and sparse output

The [based chain interface](chain_complex.md) supplies differential matrices,
cycle and homology representatives, and ambient coordinate lifts. Its
`generated_chain_complex` function accepts dense arrays and `SparseTensor`
objects. A sparse object's declared degree and shifts determine its faces;
the dimensions of its ambient array do not replace that grading.

The dimension-only routines cache normalized restrictions within a degree and
discard zero and duplicate rank columns over the selected field.
