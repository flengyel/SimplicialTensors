# Exact chain complexes and tensor representatives

The modules [chain_complex.py](../../src/simplicial_tensors/chain_complex.py) and
[tensor_chain_complex.py](../../src/simplicial_tensors/tensor_chain_complex.py)
provide finite based chain complexes over the rational field or a prime field.
They expose differential matrices and representatives as well as homology dimensions.

## Fields, bases, and differentials

Let $F=\mathbb Q$ or $F=\mathbb F_p$ for a prime $p$. For $q\geq0$, let
$c_q$ be nonnegative integers, zero outside finitely many degrees. A based
complex has $C_q=F^{c_q}$ and matrices $D_q:C_q\to C_{q-1}$ satisfying
$D_{q-1}D_q=0$ for $q\geq1$, where $C_{-1}=0$.
Matrices act on column vectors. Degree zero has the zero differential
$D_0:C_0\to0$, represented by a matrix of shape $(0,c_0)$.

`ExactField(modulus=None)` selects the rationals; `ExactField(p)` selects
$\mathbb F_p$. Inputs are Python or NumPy integers, `Fraction`, or SymPy rationals.
Floating-point coefficients are rejected. Reduction modulo $p$ requires each
rational denominator to be invertible modulo $p$.

`ChainComplex(dimensions, differentials, *, modulus=None, lifts=None,
ambient_bases=None)` checks matrix shapes and the chain identity in the selected
field. It stores immutable copies. Finite-field entries are canonical integer
residues; use `model.field.matmul`, `rank`, `nullspace`, and `coordinates` for
field arithmetic on these matrices.

```python
import sympy as sp
from simplicial_tensors.chain_complex import ChainComplex

circle = ChainComplex((1, 1), (sp.zeros(0, 1), sp.zeros(1, 1)))
assert circle.homology().homology_dimensions == (1, 1)
assert circle.homology_representatives(1) == sp.Matrix([[1]])
```

`model.homology()` returns the existing `GeneratedHomology` summary.
`cycles(q)` and `boundaries(q)` return column bases for
$\ker D_q$ and $\operatorname{im}D_{q+1}$ in chain coordinates.
`homology_representatives(q)` returns cycle columns whose classes form a basis
of $H_q=\ker D_q/\operatorname{im}D_{q+1}$. Missing degrees have dimension zero.

## Ambient representatives

An optional lift $E_q:F^{c_q}\to F^{a_q}$ has independent columns.
`ambient_bases[q]` labels its rows, and `model.lift(q, coordinates)` applies
$E_q$. Identity lifts and numbered row labels are the defaults.

For a quotient complex, a lift chooses a representative of a chain class.
The boundary of a lifted quotient cycle can belong to the discarded subcomplex
without vanishing in the original ambient complex. The stored lift matrices
therefore do not assert a separate ambient chain-map identity.

## Tensor-generated complexes

`generated_chain_complex(tensor, *, missing_face=None, modulus=None)` constructs
the normalized complex of the submodule generated by one tensor. A dense input
has degree `min(shape)-1`. A `SparseTensor` retains its declared degree and axis
shifts; tail coordinates add no simplicial faces.

The construction takes normalized injective face images as generators and uses
exact column bases. With `missing_face=j`, it quotients by the submodule generated
by the other faces. Rows of the lift matrices are labeled by tensor coordinate
tuples. See [exact tensor homology](homology.md) for the normalization convention.

```python
from simplicial_tensors.rank_shifted import SparseTensor
from simplicial_tensors.tensor_chain_complex import (
    generated_chain_complex, sparse_generated_homology,
)

tensor = SparseTensor(1, (100, 100, 100), {(0, 1, 101): 1})
model = generated_chain_complex(tensor)
assert tensor.shape == (102, 102, 102)
assert model.homology().homology_dimensions == (0, 1)
assert model.ambient_bases[1] == ((0, 1, 101),)
assert sparse_generated_homology(tensor) == model.homology()
```

Sparse construction allocates coordinate columns on the finite supports of the
generators and their boundaries. It does not allocate the dense ambient tensor.
Face enumeration and exact basis calculations can still grow with the generator
degree and support size. The dimension-only dense routines remain available as
`generated_homology` and `relative_horn_homology`.
