# Exact homology relative to a horn

[experiments/normalized_moore_complex_homology.py](../../experiments/normalized_moore_complex_homology.py) computes the homology of a tensor-generated simplicial module relative to the submodule generated by its included horn faces.

For a tensor $T$ of degree $n$ and omitted face $j$, let $A=\langle T\rangle$ and let $L$ be the simplicial submodule generated by $d_iT$ for $i\ne j$. The script computes the homology of $N(A)/N(L)$, where

$$
N_q(A)=\bigcap_{i=1}^q\ker(d_i:A_q\longrightarrow A_{q-1}),
\qquad \partial_q=d_0\quad(q>0).
$$

The unaugmented differential out of degree zero is zero. Normalization is exact, so this quotient computes relative homology.

Run from an installed checkout with NumPy and SymPy.

~~~sh
python experiments/normalized_moore_complex_homology.py
python experiments/normalized_moore_complex_homology.py --seed 123 --modulus 2
~~~

The default seed is 123. Each tensor has uniformly sampled integer entries in $-5,\ldots,5$. The script tests shapes `(3,3)`, `(4,4)`, `(2,2,2)`, and `(3,3,3)`, using the same tensor for all omitted faces of a shape. It prints the quotient's normalized dimensions, differential ranks, and relative Betti numbers. No files are written.

The helper `relative_homology_dimension(shape, j, *, seed=123, modulus=None, tensor=None)` returns the relative Betti number in degree `min(shape)-1`. Supply `tensor` to replace the sampled input. Its shape must match `shape`. The coefficient field is $\mathbb Q$ by default, or $\mathbb F_p$ for a prime modulus.

All computations use [the shared exact homology implementation](../api/homology.md). Rank calculations impose the ambient linear relations among the tensors, including relations involving zero. The helper `key_tensor` preserves both shape and entry order.
