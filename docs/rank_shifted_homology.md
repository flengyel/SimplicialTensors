# Rank-shifted tensors, graph homology, and reduced smash products

The module `simplicial_tensors.rank_shifted` implements sparse tensors over
the rational numbers with an explicit simplicial degree. It represents

\[
X_p(\mathbf c;\mathbb Q)
=\mathbb Q^{\prod_{a=1}^k[p+c_a]},\qquad c_a\geq0.
\]

Here `[m]` means `{0,...,m}`. Thus axis `a` has length `p+c_a+1`.
The shifts enlarge the tensor axes; they do **not** add face or degeneracy
indices. In degree `p`, the permitted indices are `0,...,p`. Faces require
`p >= 1`. The chain complex is unaugmented, so `boundary()` on a degree-zero
tensor raises `ValueError` rather than inventing a degree-minus-one tensor.

The mathematical definitions and proofs are in
[`tex/rank_shifted_homology.tex`](../tex/rank_shifted_homology.tex), included
in the main manuscript. The implementation uses `Fraction` coefficients;
the representation theorems in the manuscript hold over every field.
The code does not implement finite-field arithmetic or integer torsion.

## Operators

```python
from fractions import Fraction
from simplicial_tensors.rank_shifted import SparseTensor

t = SparseTensor.unit(1, (2, 2, 2), (0, 1, 3), Fraction(1, 2))
assert t.shape == (4, 4, 4)
assert t.face(0).nnz == t.face(1).nnz == 0
assert t.normalize() == t
```

Only nonzero coordinates are stored. Degrees and shifts are part of the
type checks performed by the operations.

| Mathematics | Python operation |
| --- | --- |
| Tensor unit \(E_m\in X_p(\mathbf c)\) | `SparseTensor.unit(p, shifts, index)` |
| Face \(d_i\) | `t.face(i)` |
| Degeneracy \(s_i\) | `t.degeneracy(i)` |
| Boundary \(\sum_{i=0}^p(-1)^i d_i\), \(p\geq1\) | `t.boundary()` |
| Moore projection onto \(\bigcap_{i=1}^p\ker d_i\) | `t.normalize()` |
| Levelwise tensor product, concatenating axes | `t.outer(u)` |
| Inclusion obtained by enlarging fixed tails | `t.pad_shifts(larger_shifts)` |

Normalization applies the corrections
`t = t - t.face(i).degeneracy(i - 1)` in descending order `i=p,...,1`.
The normalized differential is `face(0)`, not the normalization operator.

## Graph representation

Number vertices `1,...,V` and supply an ordered list of oriented edges.
Repeated edges, loops, and isolated vertices are allowed. Edge orientation
fixes the signs in the incidence matrix. Choose `r >= max(V,E)`.

\[
a_v=E_{0,v,v},\qquad
T_j=E_{0,u+1,u+1}+E_{1,v+1,v+1}+E_{0,1,j+1}
\quad(j:u\longrightarrow v).
\]

The endpoints are `T_j.face(1) == a_u` and `T_j.face(0) == a_v`.
The normalized edge is

\[
T_j-s_0a_u
=E_{1,v+1,v+1}-E_{1,u+1,u+1}+E_{0,1,j+1}.
\]

Its last coordinate is an independent marker for the edge, and its
normalized boundary is `a_v - a_u`. Consequently the generated simplicial
submodule has precisely the graph's chain complex in normalized degrees
zero and one. This is not the simplicial submodule generated by a graph's
single adjacency matrix.

```python
from simplicial_tensors.rank_shifted import graph_embedding, petersen_edges

graph = graph_embedding(10, petersen_edges())
assert graph.shift == 15
assert len(graph.edge_tensors) == 15
```

The Petersen example has normalized dimensions `(10,15)`, boundary rank
`9`, and rational Betti numbers `(1,6)`. The graph's higher normalized
degrees vanish. The ambient shifted DSTM has zero positive-degree
homology; a generated submodule can have cycles whose ambient fillings
are outside that submodule.

## Reduced smash product

For pointed simplicial sets `S,T`, reduced free modules satisfy

\[
\widetilde{\mathbb Q}[S\wedge T]
\cong \widetilde{\mathbb Q}[S]\otimes
       \widetilde{\mathbb Q}[T].
\]

The tensor product is taken degreewise. `outer()` concatenates the axes
and shifts and commutes with faces and degeneracies. Injective
representations therefore remain injective after tensoring over a field.
This models the reduced free module on the smash of the original pointed
simplicial sets, not the smash of the underlying sets of entire vector
spaces. Without basepoint reduction, tensoring free simplicial modules
models the Cartesian product instead.

For a circle, let `a = E01` in degree one with two axes and zero shift.
Its two faces vanish. In the tensor square, the degree-two shuffle cycle is

\[
z=s_1a\otimes s_0a-s_0a\otimes s_1a.
\]

```python
from simplicial_tensors.rank_shifted import circle_generator

a = circle_generator()
z = a.degeneracy(1).outer(a.degeneracy(0)) - a.degeneracy(0).outer(a.degeneracy(1))
assert z.nnz > 0
assert all(z.face(i).nnz == 0 for i in range(3))
```

The normalized tensor square has dimensions `(0,1,2,0)` in degrees zero
through three, with degree-two boundary rank `1`. Its reduced homology is
therefore one-dimensional in degree two and zero elsewhere. In particular,
the degree-one element `a.outer(a)` is a boundary; simply tensoring cycle
representatives in the same degree does not add their homological degrees.
The shuffle map supplies the degree addition. Eilenberg--Zilber gives a
chain homotopy equivalence between normalized levelwise tensor products
and tensor products of normalized complexes, not an equality of complexes.

## Reproduce the computations

From the repository root:

```bash
python -m pip install -e .
python -m pip install pytest
python -m pytest -q
PYTHONPATH=src python experiments/rank_shifted_homology.py
```

To write the same report to a chosen path:

```bash
PYTHONPATH=src python experiments/rank_shifted_homology.py --output results.json
```

The checked-in reference output is
[`rank_shifted_homology_results.json`](rank_shifted_homology_results.json).
All ranks are computed exactly over the rationals after restricting to the
union of occurring coordinates. The examples test tensor representatives,
face maps, normalization, and boundary ranks; they do not merely substitute
vertex and edge counts into a Betti-number formula.

## Storage and computational scope

A degree-`p` dense ambient tensor would have
`prod(p+c_a+1)` coordinates. The Petersen representation has 4,913 ambient
coordinates per degree-one tensor, but stores three entries per edge:
45 entries across the 15 edge tensors, plus ten entries across the vertices.

For tensors with `m` and `n` stored entries, a face examines `m` index
tuples; an outer product produces at most `m*n` entries. A degeneracy can
produce up to `2**k` entries from each entry of an order-`k` tensor.
Repeated degeneracy and normalization may therefore increase support
substantially. These are entry-count bounds, not bit-complexity estimates
for arbitrary-precision rational arithmetic.

The example's rank computation uses dense matrices on the occurring
coordinates. It is intended to verify these representations and is not
claimed to outperform conventional sparse incidence-matrix methods.
General hypergraph homology and automatic embeddings of arbitrary finite
simplicial complexes are not implemented here.
