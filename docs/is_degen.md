# `is_degen` documentation

## Location
- Function: `is_degen(a: np.ndarray) -> bool`
- Source: `src/simplicial_tensors/tensor_ops.py`

## Purpose
`is_degen` decides whether a tensor `a` lies in the degenerate submodule generated by simplicial degeneracy operators.

In code, it is implemented as:

```python
def is_degen(a: np.ndarray) -> bool:
    return decompose_degen(a) is not None
```

So the actual test is delegated to `decompose_degen`.

## Mathematical criterion used
Let
- `shape(a) = (n_1, ..., n_k)`
- `d = dimen(a) = min(shape(a)) - 1`
- `s_i` denote the `i`-th degeneracy operator (`degen(..., i)` in code), for `i = 0, ..., d-1`.

The tensor is declared degenerate iff there exist tensors

`b_0, ..., b_{d-1}` of shape `(n_1-1, ..., n_k-1)` such that

`a = sum_{i=0}^{d-1} s_i(b_i)`.

This is a linear membership test in the span of degeneracy images.

## How `decompose_degen` checks this
1. Build a combined linear system matrix `S` with helper `_get_degeneracy_system_matrix(a)`.
   - Each column of `S` is `flatten(s_i(e_j))`, where `e_j` is a standard basis tensor in shape `(n_1-1, ..., n_k-1)`.
2. Flatten `a` to a vector `v`.
3. Solve `S x = v` using SymPy exact linear algebra (`gauss_jordan_solve` over rational entries).
4. If the augmented system is inconsistent, return `None` (not degenerate).
5. If consistent, set free parameters to `0` to pick one canonical particular solution.
6. Reshape blocks of `x` into tensors `b_i` and return them.

`is_degen(a)` is therefore `True` exactly when that solver finds a consistent decomposition.

## Notes and edge behavior
- The decomposition is generally not unique; code returns one particular solution.
- Current implementation treats tensors with `dimen(a) <= 0` as non-degenerate (`decompose_degen` returns `None`).

## Quick consistency check (reduced run)
Using `experiments/count_standard_basis_tensors.py` with shapes `(3,3)`, `(4,4)`, `(3,3,3)`:
- `(4,4)` produced `0` non-degenerate basis tensors (all `16` were degenerate), matching `k=2 < d=3`.
- `(3,3)` and `(3,3,3)` produced non-degenerate basis tensors, consistent with `k >= d`.
